# vibedataset

gqcdataset 研究项目的远程仓库。研究目标是利用已有量子化学信息，以明确的科学定义和质量要求推进数据补全与持续扩展。

## Codex 从这里开始

1. 读取根目录 [AGENTS.md](AGENTS.md)。
2. 读取 [Codex Goal 主任务](handoff/gqcdataset_codex_goal/CODEX_GOAL.md)，将其作为本阶段目标。
3. 按 [交接包导航](handoff/gqcdataset_codex_goal/README.md) 读取背景、源码协议、开放研究路线和验证要求。
4. 开始完整源码获取、固定版本、前人能力审计，再依据证据推进路线与实现。

## 当前阶段

交接材料包含 38 个研究／软件条目、31 个已核实仓库入口、研究与验证协议、证据模板、本地源码清点工具及两份原始 PDF。完整第三方源码尚未包含在交接包中；完整获取、源码审读与科学实验属于接管后的工作。

信息充分性、剩余科学程序生成、联合信息获取、目标质量控制和资产持续扩展五条主线保持开放。原始聊天中的具体物性、数据集和样本数是历史候选，不代表已确定的唯一课题或已完成的实验。
