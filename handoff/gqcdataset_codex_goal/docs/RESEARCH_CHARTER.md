# 研究命题与开放主线

更新：2026-11-18。状态：研究规划输入；以下贡献与收益均为候选，尚非已证实结论。

## 1. 总体定位

gqcdataset 面向已有但不完整的量子化学数据，研究科学信息的复用、增量获取与持续扩展。目标是把已有观测、电子态、方法定义和质量要求接入可执行的科学计算，判断还缺什么、以何种代价获得，以及本次应保留哪些资产供未来使用。

最终希望证明的命题是：**在一致的科学目标下，改进信息表示、依赖处理和计算组织，可以增加可用物性覆盖、减少新增计算，并明确给出质量边界；新产生的信息又能继续支持后续扩展。**

这只是待检验的总命题。保存波函数、统一接口、热启动、批处理、缓存或增加几个字段本身都有价值，但不能未经最近邻比较，就将这些已有思想全部列为项目的方法创新。

## 2. 主线一：目标相关的信息充分性

**核心问题**：给定一组带有科学身份的已有资产，如何判断它对某个目标是否足够，或者至少能省去哪些计算？

研究对象可包括观测量、状态矩阵、轨道、模型参数、约束、响应及其组合，不预设必须恢复全态。例如，同一状态和约定下，若目标算符确为已知算符的线性组合，则相应期望值也满足该线性关系；这说明目标充分性可能弱于全态充分性。但更一般的关系必须逐条证明适用条件。

**候选机制**：能够检查前提的充分性规则；带有表示转换条件的资产匹配；区分直接适用、可转换、仅可作初猜与不可用的判定；对缺失依赖给出可解释结果。

**必须比较的解释**：收益是否已经能由成熟后处理、手工规则、同输入缓存或简单字段匹配获得？新机制是否真的处理了跨来源、部分信息或目标依赖，而非仅给已有工作换名称？

**可证伪方向**：构造表面字段相同但方法、状态、基组、约定或响应需求不同的情形。如果规则仍错误地接受复用，充分性机制不成立；若规则保守到几乎无法复用，也应计入覆盖损失。

## 3. 主线二：让已有数据参与科学程序生成

**核心问题**：同一目标在已有信息不同的条件下，能否生成不同且科学含义一致的剩余计算？

这里最关键的区分是：状态的**当前数值已知**，不代表状态对外部参数的**方程依赖已消失**。使用存档状态替代前向求解时，导数和响应路径仍可能需要隐式微分、伴随或专门响应求解。

**候选机制**：受科学前提约束的替代与化简规则；保留隐式依赖的状态绑定；多目标共同依赖识别；几何、方法、状态或表示变化后的失效传播；与自动微分相协调的剩余程序生成。

**必须比较的解释**：收益是否来自手工波函数后处理、普通公共子表达式消除、成熟组合计算 driver 或工作流缓存？项目新增之处应能落到规则、条件、依赖表达或执行能力上。

**可证伪方向**：对有无存档状态两条路径比较目标数值、导数和响应；设计会触发状态分支或依赖失效的输入。只比较固定态能量相等，不能证明自动微分路径正确。

## 4. 主线三：数据集级的信息获取与计算规划

**核心问题**：在一组目标与预算下，下一项最值得执行的科学计算是什么？一次计算能服务多少样本、物性或后续任务？

决策对象可以是分子、构型、物性、状态、响应、方法层级或精度。计算选择应计入读取、转换、验证、学习、调度、失败和必要重算的代价。机器学习可以提供初猜、预测代价、估计风险或选择新增计算，但具体角色需要单独评价。

**候选机制**：把共享依赖与复用机会纳入成本模型；联合决定目标顺序与状态保存；依据已观测失败更新计划；以可用信息收益而非单个任务完成数衡量计算价值。

**必须比较的解释**：是否只需合理批处理、按分子排序、常规热启动或简单贪心就能取得同等收益？规划成本是否超过节省？某一硬件或数据顺序上的结果能否迁移？

**可证伪方向**：随机化任务顺序、切换缺失机制与硬件条件，和强的共享计算基线比较。必须区分“为每条记录获得指定 QC 标签”的任务与“预算内近似建模”的任务；主动采样不能冒充前者已完成。

## 5. 主线四：目标物性相关的质量控制与混合补全

**核心问题**：已有信息对当前目标已经好到什么程度？哪一步新增计算最能提高目标质量？

状态残差、目标误差和模型偏差不是同一量。小残差并不普遍保证所有物性的误差都小；稳定性、条件数、近简并和状态分支等都可能影响判断。经验吻合、校准估计与严格误差界必须分开表述。

**候选机制**：目标相关的误差估计；基于证据的接受、拒绝与精修规则；共享状态下的多目标精度分配；对预测状态进行必要修正；分别表达学习误差、数值误差和模型近似误差。

**必须比较的解释**：收益是否仅来自放松统一阈值、选择容易样本，或用不同理论方法替代了目标？验证集是否独立，校准是否在适用范围内，错收与拒收是否同时统计？

**可证伪方向**：加入困难与分布变化样本，检查目标误差超标率及其置信信息；如果接受准则只在校准数据上有效，应收缩结论而非继续声称通用保障。

## 6. 主线五：面向持续扩展的资产保存

**核心问题**：一个数据集应该保存哪些中间信息，才能在存储、维护和未来新增计算之间取得更好的权衡？

候选资产包括最终标签、密度、轨道、相关方法中间量、响应、压缩表示及重建元数据。保存格式和已有标准是基础设施；研究贡献应落到如何依据未来任务选择保存、恢复、转换与重算。

可研究的成本形式为：

\[
C_{\mathrm{save}}+C_{\mathrm{maintain}}+
\mathbb{E}_{T\sim\mathcal{D}}[C_{\mathrm{additional}}(T\mid A)].
\]

其中资产集合为 \(A\)，未来任务分布 \(\mathcal{D}\) 必须显式说明或进行敏感性分析；不能假设已经知道所有未来用途。

**候选机制**：按目标族选择保留量；可验证的压缩与恢复；版本变化后的失效识别；跨轮次复用与成本模型。

**必须比较的解释**：与只存标签、保存完整状态、按需重算、简单压缩等策略比较。不能只统计第二轮运行时间，而忽略第一轮生成与长期保存的成本。

**可证伪方向**：改变未来任务分布，展示收益消失或逆转的条件；如果策略严重依赖事先知道目标，应明确其适用范围。

## 7. 路线选择的共同门槛

任何准备深入的路线都应回答以下问题：

| 判断维度 | 需要的证据 |
|---|---|
| 最近邻差异 | 前人已实现能力的固定版本证据，以及本项目新增机制 |
| 科学有效性 | 适用前提、状态与物性语义、拒绝条件、失效规则 |
| 可证伪性 | 明确的失败预测、竞争解释与能够区分解释的实验 |
| 成本收益 | 包含所有新增步骤的端到端代价及合理强基线 |
| 覆盖与迁移 | 困难样本、不同缺失模式、跨来源或跨任务检验 |
| 长期价值 | 本轮输出能否继续服务未来任务，以及何时不值得保存 |
| 可实施性 | GQC、xTBloom 与生态组件的可复用能力和真实缺口 |

不设定任意固定样本数或统一速度门槛来代替科学判断。实验规模应由效应大小、方差、失败频率与研究问题决定；预算边界应记录而不是隐藏。

## 8. 合理的阶段性成果

阶段性成果可以是正结果，也可以是推翻原设想的负结果：某类信息不足以支持某目标；某种复用必须保留响应求解；验证成本抵消预期收益；保存完整状态在特定任务分布下优于压缩；某项“新能力”已被前人实现。

Codex 应把这些结果写成可追溯的证据，并更新路线。形成漂亮系统结构图、填满接口或完成大量仓库索引，都不能单独证明科研贡献成立。
