# 同目标对照

| 目标 | 同等精度与身份的最强已知路径 | 什么证据可以支持增量 |
|---|---|---|
| 本来就有的标签 | 精确查询原记录，同一物理定义/几何/质量的缓存；QCFractal 的 `find_existing` 可复用同规格结果 | 仅对原来缺失或科学身份不同、确需获取的标签报告新增覆盖 |
| 已知态上的一电子观测 | 按生产者/版本显式转换基组和 AO 轴，调用成熟后处理。AD-001 的三份记录上，手写转换和度量判别均复现标量 | 新机制应能在更多合法但部分缺失元数据的记录上得到正确结果，或准确拒绝实在无法辨识的表示 |
| 新几何或方法下的目标态 | GQC 冷 SCF、合法热启动后重新求解、PySCF 原生初猜投影。异构样本还应比较原生批处理、固定批的持续上下文及按科学身份去重 | 比较实际迭代、Fock、时间及失败后恢复；相同 SCF 入口数不能自动认定工作量相同，批入口数也不能替代物理体系计数 |
| 完整定义的组合量 | 可靠来源下的手写联合公式／QCManyBody 定向任务集／QCDB 的化学包含规则。保存每个分量后只取新增需要的子集 | 程序若只做到和手写/原生相同，记为同等能力。CBS-001 节省了代数节点，在此切片未省出可补的 CC 标签 |
| 同一 RHF 参考态、多方向的场响应与两个观测量 | 原生 block solve 提交当轮全部 RHS；经过同等检查的手写方向基；若第三轴值得预取，第一轮算齐 x/y/z 保留完整响应向量；常规获取整张极化率张量后投影。物性标签缓存只能回答其已有的观测量 | 与包含第一轮成本的直接/原生/手写方案比较 RHS、J/K 以及 IO/验证。对全部请求记录结果误差。将 dD/dF 设零是错误对照 |
| 只能预测的缺列 | 原作者属性插补、相似分子/多保真模型。使用相同分组切分与训练/推理预算 | 对比预测误差，单列失败/分布外；进入量化路径时，只能作为可能被验收或拒绝的提议，仍需目标科学程序 |

已执行分子实验、未执行数据库/学习机制与对应失败边界分别见 [前人能力表](PRIOR_ART_MATRIX.md)、[判别协议](EVALUATION_PROTOCOL.md) 和 [原始响应实验](experiments/gqc_residual_response/README.md)。
