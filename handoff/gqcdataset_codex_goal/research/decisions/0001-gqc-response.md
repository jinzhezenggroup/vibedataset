# 决定 0001　首先验证 GQC 的分子响应剩余程序

2026-11-18。关联 #1、#6、#7、#8。此决定限于首轮判别机制。用户明确以 GQC 科学编译器在同精度条件下减少量化工作为重点，保留五条路线的后续比较。

1. **采用**相同 RHF 参考态和算子的多方向响应，使用已有 GQC TensorIR 生成 C++ 和有身份的方向解。比较两份多维占虚空间分子档案；按问题、观测量及场方向发布结果和拒绝原因。这样可以区分删除了工作、仅压缩了调度、或错误冻结了响应三种解释。
2. **沿用**普通读档/投影、已有 CSE、原生 blocked、每轮显式手写方向基和预先求全三轴。第一轮产生资产和编译/验收的成本计入各自策略。GQC 的工程精度问题保留原始差值与命令供用户复核；独立数据/执行路径持续推进。
3. **保留**跨来源档案解析、组合能量、QCManyBody 片段复用作为其他场景。AD-001 的已知生产者可手写精确转换；CBS-001 的 323 个真正空位缺全部七个分量；原作者模型权重支持统计预测。上述观察削弱了从这些例子直接推出通用精确补全的理由。
4. **改线条件**为未能在精度门槛内复现直接结果、验证后净 J/K 没有改善，或普通全方向预计算更便宜。下一轮应看目标数量与方向秩、来源及资产有效性；只有新算子身份或更广化学输入经过验证时才扩展。失败方向只发布原始诊断与开销。
