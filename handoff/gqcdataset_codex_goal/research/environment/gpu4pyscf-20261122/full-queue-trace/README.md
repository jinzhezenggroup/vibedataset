# 17 个几何的四臂冷热 GPU 跟踪

n2 作业 5654 在同一张 RTX PRO 6000 上为每臂运行两个新进程。冷进程从空的私有 CuPy 与 CUDA 磁盘缓存开始，热进程读取同一臂留下的磁盘缓存。每个进程执行 17 次 SCF 和 51 条请求。原始 SQLite 和 Nsight 报告在 `n2:~/vibedataset/runs/full-queue-nsight-e603c4c/trace-5654`。本目录封存了逐事件数据的可移植副本、原始报告散列和无条件的请求分母。活动分片在校验后恢复为同一个 gzip 字节流。

| 热进程 | 请求 kernel 启动数 | 请求内板卡能耗，J |
|---|---:|---:|
| A 官方 | 152820 | 19561.213 |
| B 官方加补丁 | 227968 | 36395.517 |
| C GQC 编排 | 101527 | 14400.059 |
| D 编排加补丁 | 130166 | 18512.789 |

以上按请求范围求和，SCF 范围单独保留。每个请求都有 GPU 事件时间、H2D/D2H 字节与拷贝时间、设备分配和采样的板卡显存、板卡能耗、科学输出、文件写入及独立评分。作业 5655 从冷、热两套原始值各自重算官方参考。CPU PySCF 另行从候选 AO 密度重算物理残差。两套评分覆盖全部 408 条。每个进程的末次 fsync 成本单列。

按同一分子的三个请求配对，A/C 的生产墙时比在冷缓存时为 1.272，95% 区间 [1.213, 1.328]，热缓存时为 1.307，[1.271, 1.351]。该计时包含 profiler 对生产端的影响。公开摘要提供四臂主效应和交互项。独立 scorer 的整批时间在每个缓存状态仅登记一次。应用未独立暴露的 JIT 时间保留 unknown。硬件级 achieved occupancy 和 FLOP 计数仍受该集群的驱动权限限制。[汇总](summary.json) · [逐请求账本](request-ledger.json.gz)
