# AD-001 结果

在 QCFractal 的 13 份单点测试档案中，11 份上游计算成功，2 份保留了错误。3 份提供电子态的记录都通过固定态偶极的盲验。另 8 份成功记录缺少导出的波函数。分析运行了 0 次 SCF。三个合成反例均按预登记拒绝。[实验协议](../archive_dipole_protocol.md) · [逐记录结果](first-run.json)

| 分子 | 密度来源 | 原样读的最大分量误差 | 按标称 CCA 读的误差 | 按版本转换／度量选择的误差 |
|---|---|---:|---:|---:|
| 氟乙烷 | 轨道、最终打印的占据和空轨道能量逐项对齐 | 3.5074 | 1.5105 | 8.89×10⁻¹⁵ 以内 |
| 过氧化氢 | 导出 alpha 密度及占据轨道交叉核验 | 0.06632 | 0.22477 | 1.12×10⁻¹⁵ 以内 |
| H₂ | 导出 alpha 密度及占据轨道交叉核验，全为 s 壳 | 2.23×10⁻¹⁶ 以内 | 同左 | 同左 |

误差单位为 e·Bohr。两份含 p 壳记录均只有一个有效排列通过 CᵀSC 检查，档案转到 PySCF 时取 p 分量 0,2,1。它与运行前从生产者源码推导的手写规则完全一致。H₂ 仅有 s 壳，三条基线等价。轴不可辨认、轨道缩放错误、缺少占据证据三个合成对照分别得到 6 个可行排列、0 个可行排列和占据证据缺失。计算全程沿用存档帧和存档态。训练集、模型训练和响应求解均未参与。

**对路线的影响。** 直接以字段同名判断 AO 次序会给出可观的伪差异。独立度量检查能在这两份档案发现错误约定，但已知生产者版本的转换基线达到同等覆盖与误差。所有用于验收的偶极原已存在，直接查询即能取得；本次新增的科学证据是表示和占据的可验证条件。尚无跨软件、任意符号/旋转、混合高角动量壳或波函数质量保证。

在源码接管完成的仓库根目录，用本地 CPU 复现。参考 PySCF 2.14.0 的相关 Python 模块逐字节匹配固定发布源码，实际 libcgto 的哈希、三份密度检查、全部对照误差、文件字节数及分段实测时间在 JSON 内。该程序还核验两个参考 checkout 干净。一次短运行只用于科学验收，时间不用于速度比较。
