# #18 跨方法、基组和状态的资产可迁移边界

本实验使用固定小几何和 PySCF 2.14.0 CPU 参考，先保存科学身份，再运行目标
协议。几何以 Bohr、原点为零、AO 为实球谐，SCF 收敛阈值为 `1e-10`。比较
以下状态：

- 水的 RHF/STO-3G；
- 同一几何的 RHF/6-31G*；
- 同一几何的 B3LYP/6-31G*；
- H₂⁺ 的 UHF/STO-3G 开放壳层；
- 拉伸 H₂ 的 RHF/STO-3G 低间隙控制。

对 RHF/STO-3G 密度到 RHF/6-31G* 使用 PySCF 的 AO 投影作为初猜，对
RHF/6-31G* 密度到 B3LYP/6-31G* 使用同基组初猜。投影或种子只影响收敛
路径，不改变目标方法、基组、电子数、自旋、状态分支或质量门槛。每个目标
都另做冷启动，比较能量、偶极、轨道间隙、收敛周期和用时。

响应语义用同一水几何的有限外场作独立控制。零场密度冻结导数严格为零，
正负 `1e-3` 原子单位外场重新收敛后得到的偶极导数作为弛豫响应。已有 GQC
RHF/STO-3G 直接/伴随/CPHF 和冻结态控制另列在
`experiments/gqc_residual_response/report.json`，不把 PySCF 有限场结果写成
GQC 原生响应。

表示控制反转 AO 顺序。已知且带元数据的排列往返保持密度，未识别的排列在
不变换算符时改变偶极并必须拒绝。Psi4/QCSchema 的实际 p 轴转换和占据证据
另由 `experiments/archive_dipole_protocol.md` 固定，不以度量本身猜测轴。

另用锁定的 Psi4 1.10 源码提交 `f2492db10de56b30b188239bdc6b4cfbc4a23bd5`
运行同一几何的 RHF/STO-3G、RHF/6-31G*、B3LYP/6-31G* 和 H₂⁺ UHF 目标。
运行包固定为 `python=3.13, psi4==1.10, einsums==1.1.2, libxc-c==7.0.0`，
显式设定 `puream=true`、`scf_type=pk`、Bohr 几何和零原点。Psi4 与 PySCF
的四项最大能量差为 `5.24×10⁻⁸ Eh`，最大偶极差为 `1.82×10⁻⁸ au`。

## 分类规则

- `direct_reuse` 要求几何、原子序、电子数、自旋、方法、基组、状态分支、
  AO/MO 表示、单位、原点、算符和导数语义全部相同，并且已有质量证据仍在
  适用域内。
- `initial_guess_only` 允许把旧密度或轨道投影到目标表示，但目标必须重新
  收敛并重新验收。
- `refine_required` 表示资产可帮助初始化或定位，但目标方法/性质改变，必须
  在目标协议下精修后才能发布。
- `reject` 表示身份、表示、原点或响应语义无法由绑定证据合法转换。
- `reject_and_recompute` 表示目标科学问题发生改变，保留旧资产只能作为审计
  线索，目标必须重新求解。
