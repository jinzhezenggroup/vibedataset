# RES-001　有响应存档时的补全结果

水在三个混合场方向上的总偶极响应和首原子 Mulliken 电荷响应全部通过独立检查。已知 x、y 方向的解把第二轮新求解的右端从三个降为一个，计入两次旧态验收和三次发布复核后，水的物理响应算子调用次数仍为 25 次。LiH 与直接 GQC 及独立 CPHF 一致，但预登记的两步长有限场未全部通过。两份样本都保留在分母内。[原协议](protocol.md) · [逐方向、逐分子原始值](report.json)

| 分子 | 新 RHS，直接／规划 | 实际 J/K，直接／手写／规划 | 规划与直接最大差 | 独立 CPHF 最大差 | 有限场最大差，5×10⁻⁴／2×10⁻⁴ | 分子验收 |
|---|---:|---:|---:|---:|---:|---|
| H₂O | 3／1 | 25／25／25 | 1.25×10⁻¹⁴ 以内 | 6.34×10⁻¹³ 以内 | 8.89×10⁻⁷／1.44×10⁻⁷ 以内 | 通过 |
| LiH | 3／1 | 23／17／17 | 6.93×10⁻¹⁴ 以内 | 4.94×10⁻¹¹ 以内 | 1.266×10⁻³／2.025×10⁻⁴ | 未通过 |

每一行分别比较相同单位、相同分量的数值；JSON 数组前三列为 dμ/dt，第四列为 dq₀/dt。偶极和电荷响应的单位及各自适用的绝对门槛见协议。水的计划与手写观察值逐项一致；在这个已知任务上，编译器获得的是自动生成剩余工作和复核记录的能力。GQC 原生 blocked 路径已经共享多右端的算子工作。若冻结密度，两类响应均为零，水与独立 CPHF 的最大差会达到 4.36。LiH 在 x+z 方向的 z 偶极分量差值最大；两个有限场差值的比与步长平方比相近。本次未判定该差异的具体来源，未改变阈值或步长。

**实际成本。** 两份分子各从固定库内已有的 RHF S/h/F/C/ERI 档案开始，没有重跑历史状态生成。每个分子重新算一次 Fock 来验证物理身份和存档 F。第一轮生成 x/y 解各用了 20 次 J/K，向量原始容量分别为 160／128 B，带身份和校验和的 JSON 文件为 1198／1068 B。第二轮采用相同的解析精度与最终真残差检查。首轮执行规划路径时，两份分子的本地 CPU 重建核第一次 JIT 分别约 0.43／0.45 秒；直接 blocked 的对应第二轮总墙时为 0.0062／0.0062 秒。本次没有可主张的端到端提速。另为验收实际重收敛 26 次零场／正负外场 PySCF RHF、做 2 次独立批 CPHF，并对每份分子实跑身份错误和校验正确但物理残差错误的回退。所有新增编译、求解、回退和验收的日志均可复查。[运行日志](events.jsonl.gz) · [水响应资产](water-round1.json) · [LiH 响应资产](lih-round1.json)

**复现。** 从仓库根目录使用已锁定的 GQC、PySCF 源码，与源码相符的 PySCF 2.14.0、NumPy 2.5.5、C++ 11.4.0 和 sccache 0.16.0。GQC 的 CPU 编译器生成并通过 ctypes 执行本地 C++ 共享库，包含轨道 JVP、实际 J/K 收缩、观测量和剩余重建。最终 JSON 记录源 pin、配置/驱动/规划器散列、环境、逐次真残差、每次有限场 SCF 的能量、周期数和观测值。生成物在运行目录 compiled/ 中，由原始事件绑定 SHA-256。首个启动缺少 sccache/ccache，止于第一次编译，未进入响应求解；补足启动依赖后使用原输入重试。[启动失败及修复](launch-attempt.json)
