# 既有标量和请求记录的收录条件

以 `b5359eba67e2215bcc0c050cd5d55500ac5ef265` 的 17 个 QM9 候选、两个 v2 索引和固定算符为比较对象。待检验假设是已有第三方文件保存某些方向的合格读数，足以在真实缺项上形成可用操作数。竞争解释包括只保存零场性质、保存不同响应、另有波函数可用，以及请求是数据生产过程的固定安排。

- 对照每个值的输入成员、原子序、坐标和轴、原点、电子数与自旋、状态分支、方法、实际基组、场耦合符号、读出和单位。q0 是首原子 Mulliken 净电荷，r2 和 zz 是原点固定的电子二阶矩对均匀场的导数。外部结果还需有可复核的精度及来源记录；零场数值、同名张量和未校验拟合值各保留其原定义。
- 查 QM9 正式坐标／性质发布的全档字段与 17 个成员；查固定 QCFractal 源码树中已发布的 QCSchema 单点结果；查 Psi4 的完整输入、输出及其响应实现。另查询当前公开 QCArchive 目录或公开发布的混合偶极／四极矩响应表，从可实际读取的数据逐项判断。遇到网络或访问限制时保留网址、错误、获取条件及未获取范围。
- 在检查范围内分别登记标量、分子轨道／密度、外场方向响应向量、质量证据以及分批请求的时间／来源。可识别的分子或记录创建顺序和实际用户索取分量的历史各自记录。缺少向量只说明该文件的交付内容。
- 这些来源若均不能直接供应目标历史，把自然观测支持的适配数量与现有十种受控掩码的结果分别报告。只有实际记录可绑定到同一目标与分批请求时才报告迁移或来源实测收益。记录文件大小、摘要、版本／许可证、读取／验证时间和已做读取；本环节不提交新的量化作业。
