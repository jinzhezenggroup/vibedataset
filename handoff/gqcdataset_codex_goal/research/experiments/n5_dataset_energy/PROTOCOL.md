# N5-DS-001 同协议能量补全与重复计算

把 QCFractal 的全部 13 份 QCSchema v1 单点/失败输入作为固定清单，重新取得每行的气相、中性闭壳层常规 RHF/STO-3G 全电子总能量（Hartree）。每行保留源归档、状态、原有方法、基组、driver 和新标签。冻结输入为文件中的原始有序核、Bohr 坐标、电荷及多重度。包括上游错误输入。数据集规模由原目录选择规则决定。[固定输入、散列与门槛](protocol.json)

- n5 已部署的 GQC 构建使用球谐、CUDA direct、FP64、150 次迭代上限、能量容差 1e−10、密度容差 1e−8、积分筛选 1e−12。使用 CP-001 配置中显式的初猜控制，全程关闭 batch 热启动。比较的是同一冷启动闭壳层分支。仅求能量。
- 科学键包含精确坐标、有序核、电荷、自旋、目标属性、单位、哈密顿量与显式基组参数身份、算法与收敛/筛选协议。在键中保存 GQC resolved model 和基组数据的哈希。研究不按名称、几何近似或分子式合并。
- 对照 A 逐行创建独立的单项批次，均冷启动。对照 B 用普通 Python 字典存储已求得的相同目标键；初次出现才执行一次单项批次。路径 C 收集相同目标键的代表，通过 GQC 原生 prepared batch 一次提交所有不同体系，在输入顺序回填。必须分别记录实际调用次数与体系数、迭代数、Fock 次数、失败与时钟；普通去重已节省的体系求解不属于批处理带来的额外收益。
- 每个唯一体系都作 CPU PySCF 2.14.0 RHF 独立计算。直接传入 GQC 固定基组包的实际系数和指数，使用球谐、Bohr 和相同电子/自旋数。PySCF 采用常规 Coulomb/exchange、SCF 能量容差 1e−12、梯度容差 1e−8，迭代上限 150。不同后端均须收敛。三条 GQC 路径每行两两能量差须 ≤2e−9 Hartree，每条路径与独立参考能量差须 ≤2e−8 Hartree。只允许全部通过的行产生合格标签，其他行保留尝试值、失败阶段和原因。
- 申请 n5 main 上 1 张 RTX 5090、4 CPU、16 GiB、10 分钟。设 N 为输入数、U 为精确唯一键数；三条路径最多 N+2U 个 GQC 体系、N+U+1 次 GQC execute、U 个 PySCF SCF。不重试、不调参。准备、执行和文件处理分别记录；一次固定顺序运行只给出该作业的实测耗时，无定量加速比验收。
