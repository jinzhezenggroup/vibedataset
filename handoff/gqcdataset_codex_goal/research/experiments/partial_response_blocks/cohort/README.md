# QM9 部分标量历史的全队列实验

**分母和精度。** 将首批 6 个、扩展批 11 个 QM9 几何全部计入。五个缺合格零场态。十个掩码共涉及六个不同的场／读出配对，对应 102 个唯一目标。其中 30 个缺态，72 个有态，25 个通过独立门槛，47 个保留诊断。每种策略在严格模式有 360 次重复请求、121 行通过。诊断模式对同算子实测的旧值另存一份输入文件，读出只保留 `raw_value`，全部 `value` 和 `qualified` 为空。独立 CPHF 和两个有限场参考只用于验收。全部路径中，与普通块的最大单分量差为 1.21×10⁻¹¹，按各读出自己的单位比较。q0 是首原子 Mulliken 净电荷的场导数，单位 e／原子单位电场。r2 与 zz 分别是电子平方半径和 z 坐标二阶矩的场导数，单位 bohr²／原子单位电场。新解及消费旧方向时的最大真残差为 3.42×10⁻¹¹。[各源、方法和单位](protocol.json) · [逐次求解](operations.jsonl.gz) · [原始独立定义](../../gqc_dual_response/protocol.md)

**历史和执行。** 每个源和掩码都从零用 `plan_cover` 选择原始可观察历史所需的最少方向，按普通单块计算。三个轴对循环测试仅已知两个交叉标量或另知第三轴两项。其余掩码覆盖完整六项、空历史、同读出两项和循环错位的非对角配对。每份历史分别写出严格标量、诊断标量和真实普通方向文件，再按每个策略读取它实际使用的文件。测量同一个历史一次，向每个候选策略归入同样的历史求解成本。向量在消费时再用物理算子检查残差，表中 7,102 次已含 216 次这类检查。10 组掩码共 120 份历史，产生 216 个 RHS、8,917 次 J/K。12 份共同算子设置另计 60 次 J/K。为比较两种模式与五种策略，此轮实际执行的所有后轮求解合计 2,883 个 RHS、109,784 次 J/K。[真实写出的 1,560 份资产](assets.tar.gz) · [逐条累计、真残差、字节和耗时](costs.csv.gz)

**适用边界。** 水 `qm9-000003` 的 `xy_4` 历史用两个伴随端点 q0、r2，共 19 次 J/K。未来三个对角请求用普通单块是 22 次，旧分块是 36 次，三轴同块、两轴同块和留历史向量均为 20 次。氨 `qm9-000002` 的六个交叉掩码及错位非对角掩码则相反，后轮从三个 RHS 降为两个，实际 J/K 从 30 升为 31。该现象在严格和诊断模式均出现。空历史和同读出两项历史下，不产生足够的共享收益，子场策略回到普通块。全部新路线逐条与普通响应核对。完整向量的优势依赖可用存储、后轮请求分布和资产校验成本。[逐掩码汇总与反例](summary.json)

**复现和计时。** 物理计算固定本仓 `2c1f4078c9b86eb5e17156feb594c8f809066476` 和 GQC `2791504cc238fe83d328fc1718080642b288222a`，使用 PySCF 2.14.0、NumPy 2.5.5、SciPy 1.18.1 和单线程 FP64。实际本机为 i7-1360P，并行四个互不共享状态的分子进程，端到端 60.285 秒。各策略的逐分子秒数之和会受到并发、编译文件缓存和 IO 的影响。严格模式历史标量总占用 92,298 字节，诊断历史为 124,691 字节。保留的历史向量包括空掩码的序列化信封。不同读出的数值容差和完整物理门槛沿用预登记。[环境、固定源码摘要](protocol.json) · [端到端时间](timing.json)
