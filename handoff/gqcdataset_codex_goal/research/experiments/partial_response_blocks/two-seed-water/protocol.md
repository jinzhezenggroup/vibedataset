# PLAN-004 追加手写对照：用两个混合电场补全三项响应

本对照在单混合场搜索的穷举检查发现边界后登记。只使用已经研究过的 QM9 水 qm9-000003，在运行下列两个混合场之前固定公式、成本口径和资格条件。本次检验覆盖这一组历史信息，不据此估计 17 个候选的总体性能。

令 D(f,o) 为固定 RHF/STO-3G 参考态、电场原点 (0,0,0) 上读出 o 对 f 方向静态均匀场的全响应。D(x,q0) 的单位为 e 每原子单位场，D(y,r2) 和 D(z,zz) 的单位为 bohr² 每原子单位场。使用 DUAL-001 中相同的几何、AO 归一、GQC 原生 RHF 响应和已归档独立参考。

1. 实际用同一 GQC 直接三轴单块产生 H(y,q0)、H(z,r2)、H(x,zz)。三项各自通过原独立门槛后才传入解码。交给两条后续路线的历史仅含标量、物理身份、单位和资格。生成它们时产生的方向向量均丢弃。
2. 从空方向缓存执行普通三轴块，一次直接求 x、y、z，只投影新请求 (x,q0)、(y,r2)、(z,zz)。
3. 对同一模型直接调用一次原生 GQC blocked solve_many，按 U=x+y、V=y+z 的顺序提交两列。对 U 读取 q0 和 zz，对 V 读取 r2 和 zz。用手写 FP64 加减计算

   ```
   D(x,q0) = U(q0) - H(y,q0)
   D(y,r2) = V(r2) - H(z,r2)
   D(z,zz) = (V(zz) - U(zz)) + H(x,zz)
   ```

   两个组合场在普通场基底的系数分别是 (1,1,0) 和 (0,1,1)。两次方向的四个投影参与上述三个目标，其中第三个需要两份新投影。独立 oracle 只用来鉴定历史和结果。每个实际扣除或加回的操作数均来自本次运行的历史回执。
4. 两条路线均使用同一个已核验 GQC 物理算子和默认 GMRES 配置（rtol 1e−12、atol 1e−13、200 次迭代）。每个新方向必须通过同一 1e−10 绝对真残差门槛。每个新标量照旧与直接、伴随、独立 PySCF CPHF 比较（绝对误差至多 1e−8），两步长 0.0005、0.0002 的有限场各自至多 1e−4。原门槛或上游资格未通过的目标保留原始诊断并将发布值留空；基础设施或求解失败保留失败费用，不重选分子、方向或历史。
5. 记录源与算符身份、RHS 和解摘要、逐列真残差、投影、四个手写 FP64 加减、两路逐目标资格与差值。分别报告源文件已有建态工作、已归档独立鉴定开销、本次共享模型准备、本次三项历史、普通/混合新响应的实际 RHS、块数、J/K 及墙时，同时列出各自承担相同准备和历史后的总数。初次验证已知道该水分子在 DUAL-001 的既有独立资格。
