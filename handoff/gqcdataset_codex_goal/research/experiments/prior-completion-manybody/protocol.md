# MB-001 既有片段计算能否补全指定相互作用能

本实验验证 QCManyBody 在固定三片段簇上已有的计算消除能力，以及调用者管理档案身份的责任。独立参照直接执行超分子能量减去三个单体能量的四项式。未截断的三体展开和仅取最终相互作用能的计算必须与这个参照一致。

- 三个片段依次为 He、H₂、H₂O，均为中性单重态。固定坐标以 Bohr 表示，见同目录驱动。所有能量均包含核排斥，单位 Hartree。
- 使用 CPU PySCF 2.14.0、RHF/STO-3G、球谐、FP64，无密度拟合。各次独立 SCF 固定一线程、能量容差 1e−13 Hartree、轨道梯度容差 1e−9、上限 120 周期。未收敛或非有限的结果不能进入档案。
- NoCP 单体使用自身基组；Boys–Bernardi CP 单体保留另外两个片段的 ghost 基函数。两种定义分别与自己的参考值比。本次只论 Born–Oppenheimer 固定几何电子能及核排斥。
- 先以独立冷启动执行两种最终目标的手写联合四项式，再运行 QCManyBody 的普通全阶明细和 `supersystem_ie_only=True` 联合计划。采用同一几何、方法和容差，要求各自目标误差 ≤ 1e−10 Hartree。
- 真实分三轮计算。第一轮只求 NoCP；第二轮加入 CP；第三轮重取两种标签。各轮只执行按核/ghost 身份、电子数/自旋、精确坐标、实际基组、求解设置和软件身份仍缺失的分量。与可直接执行的最小手写联合公式比较工作量。原生分量标签仅在一个父分子和方法映射内使用。
- 拿掉必要分量时组装应失败。把裸单体误贴到 CP 单体标签时，预期会出现能量差；目标容差仍取 1e−10 Hartree。每次量化调用先记 started，记录结果、失败、迭代数、分项时间与存储字节。不以一次短计时宣称加速。只改变一个片段坐标、保留片段编号时，检查标签冲突和科学身份失效，无需新增 SCF。
