# QM9-REF-001 分层队列与参考态生产协议

目标是给独立公开几何建立 conventional closed-shell RHF/STO-3G 的能量及零场响应计算所需的参考态。QM9 原始几何来自作者发布包，原有 DFT 标签不参与选样、拟合或新协议验收。[发布记录 v2](https://api.figshare.com/v2/articles/1057646/versions/2) · [作者数据说明](https://www.nature.com/articles/sdata201422)

1. 用 Figshare collection 978904 的正式成员 1057646 v2、文件 3195389，核对 86,144,227 字节和发布 MD5 `ad1ebd51ee7f5b3a6e32e974e5d54012`。记录压缩包 SHA-256、许可、README 与作者的 uncharacterized 清单。按 XYZ 文件每个核的元素统计非氢数，分为 1–2 与恰为 3；两层再按依次优先的 F、O、N、余下碳氢四类分层。按数值 gdb ID 取各层最小者，一层至多一个。预留空层；公布所有入选资格 ID、层大小、不在范围的数量、解析失败、来源质量标志与所有后续失败。固定文件内原子序与实验室坐标系，原子位置 Å 除以 0.529177210903 转为 Bohr。
2. 预定目标为气相全电子非相对论库仑哈密顿量，中性单重态、RHF、球谐 STO-3G、无密度拟合、FP64、总能量 Hartree。检查每个输入电子数可支持闭壳层。GQC 使用 n5 固定构建和 N5-DS-001 的原生 CUDA direct 冷启动设置，最多一批、每代表一个物理体系，逐项保留状态。GQC 的目标能量与用相同显式基组参数求解的 CPU PySCF 参考值须相差 ≤2e−8 Hartree。
3. 用 PySCF 2.14.0 为每个代表显式生成同一目标的 RHF 状态，一次 SCF，能量收敛 1e−13、梯度收敛 1e−11、最大 100 迭代、直接筛选 1e−14。保留底层实际指数/系数、S/h/F/轨道 C/轨道能/占据和完整 AO 四指标 ERI。参照 GQC 固定版本的 per-atom basis 构造、归一化缩放及轨道符号规则。检查 CᵀSC 最大偏差 ≤1e−9、Tr(DS) 电子数误差 ≤1e−8、FDS−SDF 最大偏差 ≤1e−8、独立从 h 与 AO ERI 重建物理 F 的最大偏差 ≤1e−10，HOMO-LUMO 能隙 >1e−6 Hartree。记录 PySCF 在该受限 SCF 解处的内部和外部轨道稳定性检查；仅收敛、两项稳定性均通过并满足上述阈值的参考态可作为已核验输入。它们限定在所测分支与局部扰动。
4. 每个接受项按上游 `fixture_snapshot(meta, arrays)` 兼容的 JSON + NPZ 保存，同时提供 id、来源哈希、标签类型、算符/单位/轴约定、独立运行身份和 n5 实际成本。GQC 批结果给出能量与收敛诊断；此队列的显式参考态生产者为 PySCF。部署、数据下载解压、GQC 入口/实求体系、PySCF SCF、稳定性运算、生成 ERI 与存储、复制字节按证据记账。n5 Slurm main，1 张 RTX 5090、4 CPU、16 GiB、10 分钟。不放宽门槛、不因失败替换预选成员。
