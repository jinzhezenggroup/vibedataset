# 输入矩阵精确表述下的逐行界

在读取各分子的占优余量前登记。取同一 17 个固定 QM9 输入，每份只请求 x 场的 q0。候选为既有普通三向历史档案中的 x 响应向量。生产侧只接收原零场、指定的 x 向量及其物理身份。完整标量参照仅在封存判定后进入评分。

假设是部分分子的已表示矩阵 A 可能具有严格行对角占优，从而在这个有限系统上给出确定的界。对于最大绝对分量位于第 i 项的任意误差 e，有 ||Ae||∞≥(|Aii|−Σj≠i|Aij|) ||e||∞。设 δ 为所有行差的最小值。如果 δ>0，则 q=wᵀA⁻¹b 和候选浮点读出 q̂ 的差满足

    |q−q̂| ≤ ||w||₁ ||b−Ax̂||∞ / δ + |wᵀx̂−q̂|.

把 A、b、w、x̂、q̂ 每个 FP64 实数按其二进制值转成精确有理数，所有比较和界的计算均用有理数进行。固定目标容差为精确十进制 1e−8。δ≤0 时不给此类证据。拒绝不合格的向量身份、字节/真残差和非有限输入。最大占虚维数 256，限一列一读出；不调整基底、行列缩放或阈值。5 个缺态直接计入缺失。原生物理残差另列。

本比较对装配后二进制矩阵、右端和读出所定义的实数方程给界。AO 积分、存档电子态、算子浮点装配与真实物理协议的误差属于另一层；分子评价以封存 v2 为外部对照。复用 #14 的同一装配入口，计入其实际 SVD、建模、向量校验、序列化和有理数工作。δ 与系数比较能否省去谱分解在此处只作条件说明。若这一固定基底下多数分子 δ≤0，保留缺证据分母，停止将该规则当作一般分子验收器。[相关误差估计与前人反例](../../audits/response-target-evidence.md)
