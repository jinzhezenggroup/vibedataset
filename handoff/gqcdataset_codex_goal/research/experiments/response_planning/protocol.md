# PLAN-001　后续请求未知时应保存哪些响应信息

预登记于 QM9 新分子响应计算和策略计时之前。RES-002 在同一水分子上发现，预先求三轴需 38 次 J/K，按需保存场方向需 54 次。因此本次同时允许程序保存场响应、读出量的伴随响应、或已算好的整张标量表。重点是各自能省下多少真实量化工作。数值问题记录复现条件与差值，由用户另行反馈。

## 科学目标与计划器的承诺

在固定几何、轨道规范、占据、方法与 FP64 协议下，三条外场 RHS 为 B。三种读出的轨道导数为 C。固定原点、核不动，显式项及符号按独立预登记的分子方程处理。每个标量含 CᵢᵀA⁻¹Bⱼ 项。它既能由 A Xⱼ=Bⱼ 得到，也能由 AᵀYᵢ=Cᵢ 得到。对称实现必须核验真实算子的转置作用、轴和读出缩放。冻结密度不足以给出这些场导数。

在没有其他已知代数关系的单位 RHS 模型中，已有合法列/行解可覆盖相应请求；其余每个请求至少选择一个端点。按单位成本的最少新端点是二分图最小顶点覆盖。实行经典最大匹配和交错路径公式，验证其与独立穷举结果相符。数学上的最少端点只涉及这类计划。物理 RHS 之间的线性相关、块求解内部秩处理、算子条件性、缓存、验收及时间均可改变最少实际工作。未请求的标量仍可为非零。所有物理数据均由 GQC 编译的响应或物性计算获取，选择端点本身不改变求解精度。

## 输入与请求

选择 QM9 原始发布的几何，用新建的气相中性单重态 conventional RHF/STO-3G 参考。样本在观察响应前依非氢原子数（1–2、3）和组成（优先含 F、否则含 O、否则含 N、否则仅 C/H）分层，每层取数值 ID 最小的记录。所有空层、失败及参考态生产成本均保留。训练、推理和历史 QM9 的 DFT 标签均不参与响应真值判定。

可请求的场是 x、y、z；读出为首原子的 Mulliken 净电荷 q0、电子 〈Σr²〉 和电子 〈Σz²〉，三种读出保留各自单位。下列为人为设计的请求顺序，用以判别信息复用；实际用户请求的频率未知。同一分子所有策略获得同一最初请求及候选算符/场字典，只能在每轮开始时看到本轮请求。匿名化的未来顺序、独立验证数值、最终通过/失败信息均不能供计划器提前选择。

| 轨迹 | 第一轮 | 第二轮 | 第三轮 |
|---|---|---|---|
| 稀疏后停止 | (x,r2)、(x,zz)、(y,q0)、(z,q0) | (x,q0) 与重复的 (y,q0) | 停止 |
| 逐场补齐 | 同上 | (x,q0)、(y,r2)、(y,zz) | (z,r2)、(z,zz) |
| 逐读出补齐 | 同上 | (x,q0)、(y,r2)、(z,r2) | (y,zz)、(z,zz) |

第一轮也单独记作终止前缀。首轮四项是一个需要混合求解才能以两个单位端点覆盖的例子；两种纯方向策略均需三个。后两种三轮轨迹最终请求相同的九项。首轮集合由机制区分力选定。多个轨迹的重复几何/标量和两种稠密轨迹不作独立化学样本。

## 比较与记账

1. 只存已合格标签，按本轮较少的活跃场/读出端点用 GQC blocked 求解，平局取场。
2. 按需保存直接解，及按需保存伴随解。原本已发布的目标可以精确命中。
3. 本轮最小混合覆盖，保留有效直接、伴随解和已请求合格标签。计入选图、读取、校验、剩余 RHS、物性收缩、保存和后续失败恢复。
4. 预取三轴并保存完整 3×3 标量表。对偶版本同样用三条读出。首轮承担全部九项的物理计算、发布检查与写入，后续精确命中直接查表。即使第二轮从未到达也不退还这些成本。
5. 混合覆盖顺带将已有端点能确定的标量预先求出并保存。它与只保存本轮请求的混合方案隔离额外读出的成本。独立手写/穷举验证相同新端点选择，不能把已知图算法命名为创新。
6. 各策略均在同一 FP64 表达与门槛运行，可利用块 RHS 的物理线性相关。报告原始请求、唯一项、复用命中、程序尝试、失败与回退、发布标签及故意预取的额外标签。记录真实 J/K、RHS、solver 与验收作用、编译/解算/IO/规划/验收耗时、资产实际字节。共用的分子参考态与独立 oracle 单独计费，不隐藏首次计算。样本内首次建立原生程序与已编译服务的后续工作要区分。固定顺序/重复计时的机器噪声限制须给出。计数和墙时分别判断。
7. 报告各分子、各轨迹和停止前缀。相同物理目标与独立门槛通过后才比较合格产出；其他项留原值和原因，不因科学失败删除其工作量。首轮端点少但 J/K 相同或更多、薄弱基线产生的收益、完整表预取胜出的情形均是预先允许的结果。严禁从合成的请求分布推断生产分布。

若一个分子的算子无法装入当前已检验的编译/存储路径，保留其在分母中的失败及资源回执，优先检验能合法继续的路径。病例的解析/有限场容差与具体方程在配套分子实验协议预登记。

策略运行采用每分子共用、按形状缓存的已编译 GQC 算子，每个策略/轨迹/重复使用独立的新资产目录；实际在轮间读写和验签。两次完整重放的第一次按 seed=60129+QM9 ID 排列七种策略与三条请求流，第二次反序。首次模型及编译准备单列；每条策略的常驻服务墙时不重复收费。精确标量命中只读已合格标签；未通过的旧读出不得充作已发布标量。已有 X/Y 只可作残差复核后的中间计算输入，得到新标量仍须独立验收。已知候选字典和阈值相同，计划器仅接收本轮请求与有身份的可用对象名。
