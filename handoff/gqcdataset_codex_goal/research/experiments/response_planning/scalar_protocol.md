# PLAN-002　从已经验收的标量恢复缺失响应

预登记于新的已知标量扣除实验之前。PLAN-001 和分子独立参考表的生成已启动，已知六个代表中有两个缺合格基态、一个分子的部分标量未通过独立门槛。选择下列算子和掩码依据固定算法结构；不以哪个数值能通过决定是否请求。来源、可用参考及未通过记录全部计入。此实验检验既有标量改变剩余科学方程的能力。

单位电场 u₁=x、u₂=y、u₃=z，依次配对读出 q0、r2、zz。将完整 3×3 标量矩阵分两轮请求：先取其中六个非配对项留作历史观测，再请求另外三个配对项。未请求的记录不能推断为零。核/态/算子、扰动的符号和尺度、精度、单位、参考原点和轨道规范必须一致。

- 第一轮用一次 GQC block 求三条场方向，输出六个标量。真正存储标量时只写通过独立门槛的数值、对应科学身份及文档散列。独立“同时保存完整向量”以及“全表预计算”策略也从头付费，后者首轮多算三项并支付验收/存储。比较中分别报告前期、后期和累计成本。
- 若同一读出已有的另外两个场导数都合法，求一次 bₓ+bᵧ+b_z 的真实 GQC 响应，读出总量，扣除两个已知同单位标量，得到缺失项。用 FP64，不放宽 1e−10 残差及原先的直接/伴随/CPHF、双步长门槛。只有独立通过的结果可以发布。考虑减法绝对误差，不宣称对任意条件数的精度保证。
- 若某一列缺扣除项或身份不兼容，不能将其作为零。对具有充分信息的列可混合恢复，其余项回到一次直接 block。若上述方案需要至少和全部直接重算一样多的新 RHS，则用全部直接重算；发生数值或参考失败保留全部真实尝试与原因。
- 强基线包含用旧标量但重算三条直接种子、正确手写线性扣除（同样可以少求；逐项比较）、保存完整方向向量、预计算完整标量表。另做一次删去所有非配对信息的负控制，要求扣除路由明确拒绝，使用常规求解。已有 GQC 观测量有可能接近零，成功标准仍是两个有身份的扣除项，而非数值大小或把请求掩码当成物理稀疏性。
- 分开报告相同历史标量已在档案时的边际成本，及这些标量需要第一轮新产生时的累计成本。报告所有物理 J/K、RHS、跨轮读写、计时、额外投影/质量检查。此掩码是人为控制，不能据它推断天然缺失的频率。独立分子验证的额外科学计算单列。
