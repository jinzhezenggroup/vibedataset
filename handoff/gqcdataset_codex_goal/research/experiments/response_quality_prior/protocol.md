# 近奇异方向上的前人对照

在开展 #14 的分子比较前，以固定的三维对称正定系统检验两个可能的误接受来源。A=diag(1,2⁻³³,2)，b=(1,2⁻³⁵,0)，只请求第二个分量。正向降阶空间为第一坐标，标量真值由精确二进制输入单独计算。理想实数模型中正向试探态的残差二范数为 2⁻³⁵，真值与该态投影的差为 1/4。

使用 pyMOR 2026.1.1 固定树的 DWRCoerciveRBReductor 求解和估计输出。分别提供真实谱下界 2⁻³³、刻意过大的因子 1，以及能表示或不能表示所请求读出伴随解的单向基。记录 pyMOR 的修正值、误差估计、实际误差、四个接受决定和耗时。保留压缩的残差或默认数值截断可能影响估计的结果。在相同 1e−8 读出门槛下，分别检查只看 1e−10 残差、用不可靠稳定性因子和使用正确因子的行为。

对 GQC 运行其固定源码中已有的校准域、误差证据类型、留出漏判、块求解真实残差及近零右端的测试。此处的方程及源码对照不产生分子发布标签，耗时单列。采用的 pyMOR、GQC 提交及运行环境写入实测回执。[GQC 既有精度与能力](../../audits/gqc.md) · [已有正向／对偶分子审计](../../audits/response-dual-prior-adjoint.md)
